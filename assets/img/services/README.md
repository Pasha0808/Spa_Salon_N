# Home service images

Five AI-generated editorial photographs for the home-page service row. They
were generated with OpenAI's built-in image generation tool on 2026-11-11,
using the owner's supplied design example as a mood, palette and crop
reference only. The reference's people, logo, layout and text were not copied.

All final files are 900 × 780 WebP images. They are fictional marketing
photographs, not pictures of Neha staff or the Pikesville salon.

| File | Prompt subject |

| `massage.webp` | Professional hot-stone massage with cream linens and khaki accents |

Shared prompt constraints: photorealistic natural texture; warm cream,
oatmeal and muted khaki-olive palette; vertical service-card composition;
no text, logo, watermark, branded products, heavy retouching or glossy
stock-photo finish.

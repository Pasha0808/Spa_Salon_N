# Agent instructions: Neha Threading Salon & Spa website

Read these two files before changing anything:

1. **[PROJECT_BRIEF.md](PROJECT_BRIEF.md)**: what the client and developer
   asked for (dated request log), current decisions, the site map, business
   facts and open items.
2. **[README.md](README.md)**: how the code works, with how-to recipes.

## Project in one paragraph
Static website (HTML + CSS + vanilla JS, no framework, no build step) for
Neha Threading Salon & Spa, one location in Pikesville, Maryland. The owner
wants shades of green, a full-screen background video, and a soft, calm
look with crisp details (HD video, clear text). The code follows the
developer's earlier Elite Dental Lab site (github.com/Pasha0808/EliteDentalLab).
It is a prototype under client review at
https://pasha0808.github.io/Spa_Salon_N/

## Rules
- **Keep the brief current.** When the developer gives a new request,
  decision, idea or fact, add it to PROJECT_BRIEF.md (request log, decisions
  table, facts or open items) in the same change.
- **Facts come from the owner or the salon's old site,
  https://www.nehathreading.com/.** Use it for prices, services, hours and
  contact details. **Never take design inspiration from it**: the owner
  dislikes it. Design references are in PROJECT_BRIEF.md §5. Its firewall
  blocks automated access; ask the developer to save pages from a browser.
- **One location only: Pikesville.** The Canton location is closed. Do not
  mention Canton or "two locations".
- **Booking is an email request form**, not a booking service. Do not add
  one unless the developer asks.
- **Prices are per specialist.** They live in `js/specialists.js`, not
  on service pages. One template, `specialist.html?p=<slug>`, shows any
  specialist; do not create a page per person. Profiles marked
  `sample: true` are placeholders: never present them as real staff.
- **Gift Certificates is unlinked for now.** Keep the page; do not add
  links to it until the developer asks.
- **Keep it static.** No frameworks, bundlers or npm dependencies unless the
  developer asks. Relative links only, so the site keeps working under the
  `/Spa_Salon_N/` GitHub Pages sub-path. Pages stay as flat files in the root.
- **Security policy:** no inline `<script>` blocks and no `style="…"`
  attributes. JS goes in `js/`, CSS in `css/styles.css`. If you add an
  outside service, add its origin to the CSP `<meta>` in **every** page.
- **Business details and the service list live in `js/config.js`.** Don't
  hard-code the phone, address, hours or service names in pages; use the
  `data-*` hooks listed in README §3.
- **Header, menus and footer are generated by `js/site.js`.** Edit them there.
- **Every service in `js/config.js` needs a `<slug>.html` page**, and every
  service a specialist lists must exist in `js/config.js` (`npm test`
  checks both).
- **Cache-busters:** when you change a CSS, JS or video file, raise its
  `?v=N` in every page that loads it.
- **Placeholders:** mark unconfirmed content with `data-placeholder="…"`.
  Never present invented reviews, prices, team members or claims as real.
- **Hero video:** `assets/video/hero-loop.mp4` is a third-party clip used
  only as a stand-in. Keep the note about it until it is replaced, and keep
  the phone / save-data / reduced-motion rules in `js/main.js`.
- **Logo:** the leaf mark exists in `assets/img/neha-mark.svg` and inline in
  `js/site.js` (`markSVG`). Keep both in sync.
- **Design: soft, not hard-edged.** Use the tokens at the top of
  `css/styles.css`: rounded corners, soft shadows, cream and sage, Cormorant
  Garamond headings in mixed case. A hard-edged version (square corners,
  black borders, all-caps Bodoni, boxed tiles) was tried and **rejected**;
  see PROJECT_BRIEF.md §4. Keep the "sharpness": HD video, light hero
  overlay, dark readable text. Lime is never text on light backgrounds;
  orange is for tiny accents only.
- **No phone number in the header menu bar.**
- **Accessibility:** keep alt text, labels, keyboard support, visible focus,
  the product strip's pause button and reduced-motion handling.
- Never commit secrets or API keys.

## Before you finish

width (about 390 px): no sideways scrolling, menus open and close, forms

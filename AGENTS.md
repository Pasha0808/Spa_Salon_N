# Agent instructions: NEHA Threading website

Read **README.md** first. It is the full brief: the client's requests, the
five reference websites and what was taken from each, design tokens, page
structure, placeholders and roadmap.

## Project in one paragraph
Static website (HTML + CSS + vanilla JS, no framework, no build step) for
NEHA Threading, a threading salon / spa. The owner wants shades of green and
a full-screen background video like The Pearl Spa. The code follows the
developer's earlier Elite Dental Lab site (github.com/Pasha0808/EliteDentalLab).
It is a prototype for client review on GitHub Pages:
https://pasha0808.github.io/Spa_Salon_N/

## Rules
- **Keep it static.** No frameworks, bundlers or npm dependencies unless the
  developer asks. Relative links only, so it keeps working under the
  `/Spa_Salon_N/` GitHub Pages sub-path.
- **CSP:** no inline `<script>` blocks and no `style="…"` attributes. Put JS
  in `js/` and CSS in `css/styles.css`. If you add an external service
  (booking widget, analytics, map), add its origin to the CSP `<meta>` in
  **every** page.
- **Business details live in `js/config.js`.** Don't hard-code phone,
  address, hours or booking URLs in pages; use the `data-book`, `data-gift`,
  `data-phone`, `data-email`, `data-address`, `data-hours` and `data-map`
  hooks that `js/site.js` fills.
- **Header and footer are generated by `js/site.js`.** Edit them there, not
  in the pages.
- **Cache-busters:** when you change a CSS/JS/video file, bump its `?v=N`
  in every page that loads it.
- **Placeholders:** mark unconfirmed content with `data-placeholder="…"`.
  Never present sample reviews, prices or claims as real. Leave them marked
  until the owner confirms.
- **Hero video:** `assets/video/hero-loop.mp4` is a third-party clip (Sharq
  Village & Spa), used only as a stand-in. Don't remove the note about it
  until it is replaced. Keep the phone / save-data / reduced-motion rules
  in `js/main.js`.
- **Logo:** the leaf mark exists in `assets/img/neha-mark.svg`,
  `assets/img/neha-mark-light.svg` and inline in `js/site.js` (`markSVG`).
  Keep all three in sync.
- **Colours:** use the `:root` tokens in `css/styles.css`. Lime (`--lime`)
  is never text on light backgrounds; orange (`--sun`) is for tiny accents only.
- **Accessibility:** keep alt text, ARIA on tabs and menus, keyboard support,
  visible focus, and reduced-motion handling.
- Never commit secrets or API keys. The future contact-form Worker keeps its
  keys in Cloudflare.
